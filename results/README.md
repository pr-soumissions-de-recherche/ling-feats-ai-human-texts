# Results Directory

This directory contains experimental results from classification experiments.

## Structure

Results are organized by testbed and experiment type:
- `testbed{N}_*/` - Main classification results
- `ablation/` - Feature ablation study results
- `cumulative_ablation/` - Cumulative ablation results
- `global_results.json` - Summary of all experiments

## Note

Result files are generated during experiments and are not included in this repository.
