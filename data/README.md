# Data Directory

This directory contains the feature datasets used for AI text detection experiments.

## Structure

- `mage/` - MAGE benchmark dataset features (train/val/test splits)
- `cmv/` - CMV dataset features
- `raw/` - Raw text data if you have it
- `feature_consistency_report.json` - Feature group definitions and consistency report

## Note

You need to download or extract features using `elfen_extractor.py` before running experiments.
